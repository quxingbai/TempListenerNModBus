Modbus学习项目
项目1：智能温室监控系统（单个从站）
难度：★☆☆☆☆
时间：2-3天
目标：完整走通"读-处理-存-显-写"全流程

硬件配置
yaml
Modbus Slave开3个窗口（都在本机）：
├─ 端口502：保持寄存器（温度传感器）  
│  地址0：当前温度（需缩放0.1）
│  地址1：当前湿度（需缩放0.1）
├─ 端口503：线圈（控制设备）
│  地址0：加热器开关
│  地址1：加湿器开关
│  地址2：报警灯
└─ 端口504：输入寄存器（光照传感器）
   地址0：光照强度（原始值）
软件实现
csharp
// 你的上位机要做：
1. 同时连接3个端口（用不同TcpClient）
2. 每500ms读取一次所有数据
3. 自动控制逻辑：
   - 温度<20℃ → 开加热器
   - 温度>30℃ → 关加热器，开报警灯
   - 湿度<40% → 开加湿器
   - 光照>800 → 记录"强光"日志（没做）
4. 数据存到SQLite
5. WPF界面实时显示
6. 历史曲线查询（改成了实时曲线图）
